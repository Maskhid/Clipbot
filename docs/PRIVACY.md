# Privacy Policy — ClipBot

_Last updated: [11/4/2026]_

ClipBot is a private tool operated by [Peak] ("I") to publish video clips to social media accounts that I own or manage. It is not offered to the public.

**What it accesses.** When I connect one of my accounts (YouTube, TikTok, Instagram, Facebook), ClipBot receives an access token from that platform and basic profile information (account name / ID) needed to confirm the right account was connected.

**What it does with it.** Tokens are used only to upload videos and captions that I have chosen, to the account they belong to. ClipBot does not read messages, followers, or other users' data, and does not sell or share any data.

**Storage.** Tokens are stored encrypted (AES via Fernet) and can only be decrypted with a key kept as a private secret. Post history (video IDs, links, times) is kept to avoid duplicate posting.

**Deletion.** Access can be revoked at any time from each platform's settings (e.g. TikTok → Settings → Security → Manage app permissions; Google Account → Security → Third-party access; Facebook → Settings → Business integrations). Revoking makes the stored token useless. To have records deleted, contact [peaktheclipper@gmail.com].
